# STM32 Signal Analysis System

基于 STM32F407 的信号采集、分析与可视化系统，集成 ADC 数据采集、DMA 数据传输、信号特征分析、FreeRTOS 多任务调度以及 LVGL 图形界面，支持通过 AD9850 模块产生测试信号，并在 LCD 屏幕上显示分析结果。

## 1. 项目简介

本项目基于 STM32F407 微控制器，搭建了一套集信号产生、采集、分析和显示于一体的嵌入式信号分析系统。

系统通过 AD9850 直接数字频率合成器产生测试信号，利用 STM32 ADC 对输入信号进行采样，并借助 DMA 将采样数据传输至内存。程序对采样数据进行统计分析，利用方差阈值进行初步波形分类，并通过过零检测估算信号频率。最终，分析结果通过 LVGL 图形界面显示在 LCD 屏幕上。

项目主要用于嵌入式系统开发、信号采集与处理、实时任务调度以及人机交互界面的实践学习。

## 2. 主要功能

- **信号产生：** 通过 AD9850 模块产生指定频率的测试信号。
- **数据采集：** 使用 STM32 ADC 对输入信号进行采样，并通过 DMA 搬运采样数据。
- **信号特征分析：** 计算采样数据的均值与方差，进行初步波形分类。
- **频率估算：** 通过过零检测统计信号状态变化次数，估算输入信号频率。
- **实时信息显示：** 使用 LVGL 在 LCD 屏幕上显示波形分类、采样数据均值换算值及频率估算结果。
- **多任务运行：** 基于 FreeRTOS 创建 GUI 任务和 ADC 数据分析任务，并使用互斥锁协调相关操作。

## 5. 核心实现

### 5.1 ADC 与 DMA 数据采集

配置 STM32 ADC 和 DMA，实现采样数据向内存缓冲区的传输。程序设置采样缓冲区长度为 4096 个数据点，为后续信号特征计算提供数据基础。

### 5.2 波形初步分类

对采样数据计算均值，并进一步计算数据方差。当前实现通过方差阈值对输入信号进行初步分类，将结果显示为正弦波或方波。

该方法属于基于统计特征的简化分类方案，分类准确性受信号幅值、噪声、采样配置及阈值选择等因素影响，并不等同于通用波形识别算法。

### 5.3 过零检测与频率估算

以采样数据均值为参考，设置上下阈值区间，统计信号状态变化次数，并据此估算输入信号频率。

通过设置阈值区间，可以在一定程度上减少采样噪声引起的重复状态切换。频率估算精度仍取决于采样时间、信号周期、噪声水平及过零点统计方式。

### 5.4 FreeRTOS 与 LVGL 任务协同

基于 FreeRTOS 创建图形界面任务和 ADC 数据分析任务。GUI 任务周期性调用 `lv_timer_handler()`，处理 LVGL 的定时任务；数据分析任务负责采样数据处理和界面信息更新。

通过互斥锁协调相关操作，降低多个任务同时访问 LVGL 对象时发生资源竞争的风险。

### 5.5 LCD 数据可视化

使用 LVGL 创建文本标签，将信号分类结果、采样数据均值换算值和频率估算值显示在 LCD 屏幕上，便于直观观察系统运行状态。

## 8. 编译与运行

1. 克隆项目仓库：

   ```bash
   git clone https://github.com/niu-uin/stm32-signal-analysis-system.git
   ```

2. 进入项目目录，使用 Keil MDK-ARM 打开 `Projects/MDK-ARM/atk_f407.uvprojx` 工程文件。

3. 检查 STM32F407 芯片型号、时钟配置、外设引脚、ADC 与 DMA 配置，以及 LCD 和 AD9850 的硬件连接。

4. 根据实际硬件连接检查 ADC 采样通道、定时器触发方式、采样时间参数和波形分类阈值。

5. 编译工程，将程序下载至开发板。

6. 接通相应硬件并运行程序，观察 LCD 上显示的信号分类、数据均值换算值和频率估算结果。

注意：上述步骤为一般运行流程。由于工程配置与实际硬件连接可能存在差异，首次运行前应核对相关配置。
